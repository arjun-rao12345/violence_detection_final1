# SafeWatch — React + Vite

A RescueX-inspired emergency-response UI converted into a component-based React/Vite application for a violence reporting and response project.

## Added project features

- Violence reporting form
- Anonymous reporting option
- Browser location capture
- Image/video evidence upload field
- Emergency report confirmation
- AI real-time threat monitoring UI
- Violence and weapon detection alert cards
- Incident response timeline
- Police notification/assignment flow UI
- Request backup action
- Live incident map UI
- Active incident / police-unit statistics
- Emergency-focused navigation and CTA
- Responsive mobile layout

## Important

This is a frontend prototype. The report form, AI alerts, map, police dispatch and tracking UI are currently demonstration components. Connect them to your Node/Express/MongoDB backend, authentication, WebSocket/Socket.IO layer, ML inference service and a real map provider before production use.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
